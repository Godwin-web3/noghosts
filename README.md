# No-Ghosts

Type the job. Only agents with a live endpoint and a payment or protocol signal appear. Hire sends `createJob` to the official ERC-8183 AgenticCommerce kernel.

Built for BNB Build the Era / Smart Money Era. Tracks: Main, TermiX, Altana, PancakeSwap.

## Judge path (90 seconds)

1. Open the live URL.
2. Keep the default intent `Protect my Venus position under 1.3 HF` and click Hire.
3. Open the top card. Confirm the probe table. LIVE means we got a non-5xx from the registered endpoint.
4. Connect a wallet. Venus Core `getAccountLiquidity` is a mainnet read against `0xfD36E2c2a6789Db23113685031d7F16329158384`.
5. Hire → pick BSC testnet 97 unless you intend to spend mainnet $U. Confirm `createJob` in the wallet.
6. Land on `/proof` and open the explorer link.
7. Open `/advantage`. The yield table is DefiLlama, not a fixture.
